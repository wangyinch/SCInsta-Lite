# SCInsta Lite

Experimental minimal Reels controls derived from SoCuul/SCInsta 1.1.1, commit 7bb71807190518ed45d21c716704c38e45a19253. GPL-3.0; see ../LICENSE.

Build only this directory with Theos: `make -C lite FINALPACKAGE=1 DEBUG=0`. Root build scripts belong to the full upstream tweak.

Retains Reels tab hiding, manual and automatic Reels scroll blocking, and suggested Reels carousel filtering. No playback or DM data-source truncation hooks. No download, ad blocking or FLEX features are compiled. Explore remains unchanged.

Upstream tested Instagram 418.2.0. This fork has not passed device acceptance tests. No Instagram IPA, credentials or personal data are included. The library alone is not an installable app.
